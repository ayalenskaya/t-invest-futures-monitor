# Монитор фьючерсов T‑Invest → Telegram

Программа следит за девятью фьючерсами из списка пользователя: `BRV6`, `CRU6`, `GDU6`, `IMOEXF`, `MXU6`, `NGU6`, `RIU6`, `SIU6` и `SVU6`. Она анализирует реальные пятиминутные свечи и присылает Telegram‑алерты. Программа **не умеет выставлять заявки** и не содержит OpenAI API: дополнительной платы за анализ нет.

## Что присылает программа

- `🟢 ЛОНГ-КАНДИДАТ` — закрытая пятиминутная свеча пробила верх диапазона, тренд, RSI и повышенный объём подтвердили движение;
- `🔴 ШОРТ-КАНДИДАТ` — те же подтверждения для движения вниз;
- `⚪ ЖДАТЬ` — показывается при тестовом запуске, если полного набора условий нет.

Для кандидата бот указывает зону возможного входа после возврата к пробитому уровню, уровень отмены сценария/стопа и ориентир цели. В обычном режиме сообщения `ЖДАТЬ` не отправляются.

Это строгий технический сценарий, а не предсказание рынка и не гарантия прибыли. Бот не предлагает догонять цену и не выставляет заявки.

## Что требуется от вас

1. Windows 10/11 и Python 3.11 или 3.12. При установке Python отметьте **Add Python to PATH**.
2. В T‑Инвестициях выпустите отдельный токен **только для чтения**. Не используйте full‑access токен.
3. В Telegram создайте бота через `@BotFather` командой `/newbot`.
4. Откройте созданного бота и отправьте ему `/start`.

Не присылайте токены в чат и не публикуйте файл `.env`.

## Самый простой запуск

1. Дважды кликните `INSTALL_AND_SETUP.cmd`.
2. Вставьте read‑only токен T‑Invest и токен Telegram. Символы при вводе не показываются — это нормально.
3. Запустите `TEST_ONCE.cmd`. В Telegram должны прийти четыре тестовых сообщения с текущими данными.
4. Запустите `START_BOT.cmd` и оставьте окно открытым.

Если токен был отозван, просрочен или создан для песочницы, выпустите новый read-only токен для обычного счёта и запустите `CHANGE_TOKENS.cmd`. Потребуется ввести только токен T-Invest; Telegram останется настроенным. Программа проверит новый токен до сохранения.

Программа проверяет рынок раз в минуту, но использует пятиминутные свечи. Остановить её можно закрытием окна или сочетанием `Ctrl+C`.

## Бесплатный облачный запуск

Для работы при выключенном ноутбуке подготовлен GitHub Actions. Он проверяет рынок каждые пять минут по будням и хранит токены в закрытых GitHub Secrets. Инструкция для новичка находится в `GITHUB_SETUP.md`.

## Важные ограничения

- Компьютер и интернет должны оставаться включёнными.
- После экспирации срочного контракта его тикер нужно заменить в строке `TICKERS` файла `.env`. `IMOEXF` — вечный контракт; остальные тикеры зависят от срока исполнения.
- Если данных меньше 23 свечей, программа запишет это в `monitor.log` и продолжит работу с другими инструментами.
- Повтор одинакового сигнала подавляется на 30 минут. Параметр меняется через `COOLDOWN_MINUTES` в `.env`.
- Сигнал может прийти после быстрого движения. Если цена уже ушла, не следует догонять её только из-за уведомления.

## Безопасность

Настоящие токены сохраняются только в локальном `.env`, который исключён из Git. Для мониторинга достаточно read‑only токена; программа импортирует только сервисы инструментов и рыночных данных, а методов выставления заявок в коде нет.
