# Бесплатный запуск через GitHub

GitHub будет запускать проверку каждые пять минут по будням. Ноутбук можно выключать. В Telegram отправляются только `ЛОНГ-КАНДИДАТ` и `ШОРТ-КАНДИДАТ`.

## Безопасность

- Файл `.env` нельзя загружать на GitHub. Он уже добавлен в `.gitignore`.
- Три значения добавляются только через **Settings → Secrets and variables → Actions → New repository secret**.
- Имена секретов должны быть точными:
  - `TINVEST_TOKEN`
  - `TELEGRAM_BOT_TOKEN`
  - `TELEGRAM_CHAT_ID`

## После загрузки проекта

1. Добавьте три секрета из списка выше.
2. Откройте вкладку **Actions**, выберите **Futures monitor**, нажмите **Run workflow**.
3. Первый запуск должен завершиться зелёной галочкой. После этого проверки идут автоматически.

Workflow имеет только право чтения кода. Информация о последнем отправленном сигнале хранится во внутреннем кэше GitHub, поэтому боту не требуется изменять файлы репозитория.

Код репозитория будет открытым, но секреты GitHub в нём не отображаются. GitHub предупреждает, что запуски по расписанию иногда задерживаются, а в публичном репозитории расписание отключается после 60 дней без активности.
